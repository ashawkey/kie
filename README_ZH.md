# kie — 浏览器中的像素画图像编辑器

kie 是一个使用原生 ES 模块和 CSS 构建的纯静态像素画编辑器。直接在现代浏览器中打开、编辑和导出图像，无需账号、安装、运行时依赖或后端服务。

**[立即使用 kie](https://ashawkey.github.io/kie/)** · [English](./README.md) · [GitHub](https://github.com/ashawkey/kie)

## 为什么选择 kie？

- **本地处理：** 图像在浏览器中处理，无需上传到服务器。
- **无需安装：** 打开网页即可编辑，不需要账号或额外配置。
- **纯静态应用：** 没有后端，也没有运行时依赖。
- **轻量：** 使用原生 ES 模块和 CSS，运行时结构精简直观。
- **跨平台：** 可在受支持桌面平台上的最新版 Chrome、Edge、Safari 和 Firefox 中运行。
- **面向像素画：** 提供最近邻缩放、像素网格、像素级绘制、调色板、抖动等专用能力。
- **双语界面：** 支持英文和简体中文 UI。

## 适用场景

- 制作和调整精灵、图块、图标及小型游戏素材
- 清理现有像素画或重新配色
- 在保留清晰像素边缘的同时放大导出
- 在不方便安装软件的设备上快速编辑图像
- 让日常图像编辑保留在本地，而不是将文件发送到在线编辑服务
- 将多图层作品保存为 `.glassx` 项目并继续编辑

## 功能

### 打开、保存与导出

- 打开、导入或拖放图像
- 配置导出格式、缩放比例和质量
- 实时导出预览与编码后文件体积的精确读数
- 在受支持的 Chromium 浏览器中通过 File System Access API 原位保存
- 在其他浏览器中回退为下载文件
- 支持分层的 `.glassx` 项目文件

### 像素画工作流

- 像素级精准铅笔模式
- 对称像素笔刷
- 最近邻图像处理
- 可选像素网格
- 抖动、色阶压缩和像素描边效果
- 内置调色板
- 前景色与背景色控制

### 绘制与编辑工具

- 移动与变换
- 矩形选区、套索、魔棒和裁剪
- 铅笔、画笔、橡皮擦和油漆桶
- 渐变、直线、矩形和椭圆
- 吸管、抓手和缩放
- 多种选区模式与蒙版

### 图层与导航

- 图层不透明度和可见性
- 图层排序与合并
- 16 种混合模式
- 用于浏览画布的导航器
- 工具悬停帮助

### 滤镜与历史记录

- 亮度/对比度、HSV、灰度、反色、棕褐色、色阶压缩、阈值、抖动、模糊、锐化、边缘、噪声、像素化和描边滤镜，支持预览
- 有界撤销与历史记录，避免编辑历史无限增长

## 隐私说明

kie 是没有后端的静态浏览器应用。文件在浏览器本地打开和处理，使用编辑器时无需上传图像。

本地处理减少了将图像发送到远程编辑服务的需要，但并不等同于绝对安全。浏览器、设备、扩展程序、操作系统和网络等常规安全因素仍然适用。处理敏感内容时，请审查源代码并使用可信的部署版本。

## 浏览器支持与限制

kie 面向以下浏览器的当前版本：

- Chrome
- Edge
- Safari
- Firefox

直接保存回现有文件依赖 File System Access API，仅受支持的 Chromium 浏览器可以使用。其他浏览器采用下载文件的保存与导出流程，因此不同平台的浏览器能力和文件系统行为可能有所区别。

## 本地开发

kie 使用 Vite，构建结果输出到 `dist`。

```bash
npm install
npm run dev
```

创建生产构建：

```bash
npm run build
```

在本地预览生产构建：

```bash
npm run preview
```

## 技术说明

- 原生 JavaScript ES 模块和 CSS，无运行时依赖
- 基于 `ImageData` 直接绘制，保证像素级编辑精度
- 历史记录只保存脏矩形，使撤销内存保持有界
- 变换在提交前保持非破坏性
- 静态生产文件输出到 `dist`，无需后端服务
